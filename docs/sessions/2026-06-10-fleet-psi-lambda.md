## Decisions
- **ADR 0018** — Fleet-PSI EventBridge Lambda. (1) **Pool** all pumps' 5-min windows into ONE `compute_psi` (not per-pump-then-max — that duplicates each STATE row's `latest_psi`). (2) Read the **hot table** via the batcher's per-pump Query loop. (3) **FLEET STATE row + edge-triggered SNS** (mirrors ADR 0012). (4) Arm via the shared **`psi_alert_should_fire`** (ADR 0017) — no score path; PSI-only alert. (5) **Drift-only deploy** (numpy + `shared/` + reference; no sklearn/model.pkl). (6) Empty fleet = no-op. PO scope call: handler + tests + ADR only; Terraform deferred.

## Trade-offs surfaced
- **Pooling hides which pump moved** — by design; the fleet view answers "is the plant drifting," the per-pump `latest_psi` rows answer "which pump." Complementary.
- **FLEET SNS payload is scope-tagged** — `scope:"fleet"` + `score:null` (no model on the fleet path); a small, documented divergence from the per-pump payload (review §2).
- **Arm via the shared composite, not a fleet-local threshold** — the payoff of ADR 0017 §1: two AWS alert sites, one definition, no divergence (north star #6). Pinned by a structural-parity guard.
- **FLEET is a separate partition** — a plant-level row that disturbs no existing access pattern (scorer/batcher/adapter never read it).
